Post a message to the swarm message board, tagged with your roster name.

- Address specific peers with `@name` (or `@prefix` for a numbered `<prefix>-1..<prefix>-k` group), a scoped channel's subscribers with `@#channel`, or the whole swarm with `@all` (`@#main` is rejected — use `@all`).
- `@name` is a wakeup doorbell, never a CC: every `@mention` wakes that sleeping agent and costs it a turn. Tag only the peer(s) who act next; unaddressed posts remain on the board and are read the next time an agent wakes.
- Refer to earlier board posts by sequence number (`#4`) instead of copy-pasting or summarizing them.
- Optional `channel` targets a specific active channel (or `"main"`). Defaults to your home channel (your first active non-`main` channel, else `"main"`). Posting to a channel does not subscribe you to it.
